# Your first five minutes

Kestrel is an open-source database platform MVP. It combines a PostgreSQL-backed control plane, a Go key-value storage plane, and this Vue workspace. It is not a production replacement for a managed database.

## 1. Make yourself at home

Create an account to work with real server data, or choose **Explore the interactive demo** on the sign-in screen. The demo is an in-memory sandbox: it makes no API requests, and your changes disappear when you refresh.

## 2. Create a project

A project is a home for one application. Give it a name and a unique slug within your organization. Use the project switcher in the sidebar to move between projects.

## 3. Shape a collection

Open **Collections** and add fields with names, types, and required flags. For example, a `products` collection might have a required `name` string, a `price` number, and an `in_stock` boolean.

Supported field types are `string`, `integer`, `number`, `boolean`, `object`, `array`, and `null`. Unknown fields are rejected. Each record is limited to 64 KiB.

## 4. Add your first record

Open **Data explorer**, choose your collection, and select **Add record**. The editor starts with sample values. Replace them with your own JSON and save. Edits are validated by the server before they are persisted.

Search filters only the current 25-record page. **Export page** downloads that page as JSON; it is not a database backup.

## 5. Connect your application

The repository includes `@kestrel/client`, a dependency-free TypeScript client. Build it with `npm run build -w @kestrel/client`. Use it in your application with the workspace package or publish your own package after review.

```ts
import { KestrelClient } from '@kestrel/client';

const db = new KestrelClient({ baseUrl: '/api/' });
const session = await db.login({ email, password });
db.setToken(session.access_token);
const records = await db.listRecords(projectId, 'products');
```

The `/api/` path needs a reverse proxy to the control plane. The included dashboard provides this proxy. Tokens expire after 15 minutes; this client does not refresh sessions or store credentials.

## Run the complete local stack

From the repository root, run `bash scripts/setup.sh`, then `docker compose up --build`. Open the dashboard on port 3000. See the repository README for development commands, migration steps, and the verification checklist.
