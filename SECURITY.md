# Security policy

## Supported versions

Only the current development branch and v0.2 workspace code are maintained at this early stage. There are no production releases or support SLAs yet.

## Reporting a vulnerability

Please do not file public issues for exploitable vulnerabilities. Use GitHub's private vulnerability reporting for this repository if enabled, or contact the repository maintainers privately through GitHub. Include affected commit/version, impact, and a minimal reproduction where safe. Do not include customer data or publish exploit details before coordination.

The project is not yet independently audited. See [security/THREAT_MODEL.md](security/THREAT_MODEL.md) for implemented mitigations and material gaps. No security feature should be treated as a guarantee of complete protection.
